# Personal Fit

## Sobre o projeto
Eu desenvolvi este site fictício para um profissional de educação física que atua como personal trainer. O foco foi criar uma landing page estratégica para atrair alunos, oferecer avaliação gratuita e vender planos online e presenciais.

## Funcionalidades principais
* Hero com promessa de resultado e CTA para avaliação gratuita via WhatsApp
* Formulário de check-up que abre o WhatsApp com dados pré-preenchidos
* Apresentação do Método 3P com benefícios claros
* Seção de resultados com depoimentos reais fictícios
* Tabela de planos comparativos com destaque para o plano Pro
* Oferta de Desafio 21 Dias com escassez

## Tecnologias usadas
HTML5, CSS3 com design moderno, JavaScript vanilla para interações e envio

## Principais aprendizados
Ao montar este projeto eu reforcei a importância de storytelling e prova social na área de saúde. Aprendi a usar escassez ética e ofertas de entrada para reduzir a barreira inicial. Também pratiquei hierarquia visual para guiar o usuário até a conversão sem distrações.
